# 📦 Dados de Exemplo do VISÃO

## Arquivos

### mockData.ts
Dados mock para desenvolvimento.
- Câmeras fake
- Alertas simulados
- Usuários de teste

### mockRules.ts
Regras de automação de exemplo.
- Detecção de movimento
- Reconhecimento facial
- Alertas de zona

### ruleTemplates.ts
Templates para criação de regras.
- Templates pré-configurados
- Condições comuns
- Ações padrão

### sampleData.ts
Dados de exemplo para demos.
- Dados realistas
- Cenários completos

### testData.ts
Dados para testes automatizados.
- Fixtures
- Edge cases
- Dados válidos/inválidos

## Uso

```typescript
import { mockCameras, mockAlerts } from "@/data";

// Em desenvolvimento
const cameras = mockCameras;

// Em testes
const testCamera = testData.validCamera;
```
