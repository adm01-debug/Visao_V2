# 🤝 Guia de Contribuição

## Como Contribuir

### 1. Fork e Clone

```bash
git clone https://github.com/SEU-USER/vis-o.git
cd vis-o
npm install
```

### 2. Criar Branch

```bash
git checkout -b feature/minha-feature
# ou
git checkout -b fix/meu-fix
```

### 3. Fazer Alterações

- Siga o style guide
- Adicione testes
- Atualize documentação

### 4. Commit

```bash
git add .
git commit -m "feat: descrição da feature"
```

#### Convenção de Commits

| Tipo | Descrição |
|------|-----------|
| feat | Nova feature |
| fix | Correção de bug |
| docs | Documentação |
| style | Formatação |
| refactor | Refatoração |
| test | Testes |
| chore | Manutenção |

### 5. Push e PR

```bash
git push origin feature/minha-feature
```

## Checklist PR

- [ ] Testes passando
- [ ] Documentação atualizada
- [ ] Sem erros de lint
- [ ] Tipos corretos

## Code Style

- TypeScript strict
- ESLint + Prettier
- Tailwind CSS
- React hooks
