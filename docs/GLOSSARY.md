# Glossary

## Terms

### A
- **Alert**: Notification triggered by system events
- **API**: Application Programming Interface

### B
- **Bandwidth**: Data transfer capacity
- **Bitrate**: Video quality measurement

### C
- **Camera**: Video capture device
- **CCTV**: Closed-circuit television

### D
- **Dashboard**: Main overview interface
- **Detection**: AI-powered event recognition

### E
- **Edge Function**: Serverless compute at edge

### F
- **FPS**: Frames per second
- **Fullscreen**: Display mode

### H
- **HLS**: HTTP Live Streaming
- **Hook**: React custom function

### I
- **Integration**: External service connection
- **Intrusion**: Unauthorized access detection

### M
- **Motion Detection**: Movement sensing
- **Memoization**: Performance optimization

### N
- **NVR**: Network Video Recorder

### P
- **PTZ**: Pan-Tilt-Zoom camera control
- **PWA**: Progressive Web App

### R
- **Recording**: Stored video footage
- **Resolution**: Video quality

### S
- **Streaming**: Live video transmission
- **Supabase**: Backend service

### T
- **Thumbnail**: Preview image
- **Timeline**: Video playback interface

### W
- **WebRTC**: Real-time communication
- **WebSocket**: Bidirectional connection

### Z
- **Zone**: Monitored area
- **Zustand**: State management library
