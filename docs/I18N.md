# Internationalization - VISÃO

## Idiomas Suportados
- Português (pt-BR) - padrão
- English (en)
- Español (es)

## Uso

```tsx
import { useI18n } from '@/contexts/i18n';

function MyComponent() {
  const { t, language, setLanguage } = useI18n();
  
  return (
    <div>
      <h1>{t('dashboard.title')}</h1>
      <select onChange={(e) => setLanguage(e.target.value)}>
        <option value="pt-BR">Português</option>
        <option value="en">English</option>
      </select>
    </div>
  );
}
```

## Adicionar Traduções

1. Edite `src/contexts/i18n.tsx`
2. Adicione chaves em todos os idiomas
3. Use `t('chave.subchave')` nos componentes

## Formatação
- Datas: `date-fns` com locale
- Números: `Intl.NumberFormat`
- Moeda: `Intl.NumberFormat` com currency
