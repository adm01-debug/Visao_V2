# 🌍 Internacionalização - VISÃO

## Idiomas Suportados

- 🇧🇷 Português (pt-BR) - Padrão
- 🇺🇸 Inglês (en)
- 🇪🇸 Espanhol (es)

## Uso

```tsx
import { useTranslation } from "@/contexts/i18n";

function Component() {
  const { t } = useTranslation();
  return <h1>{t("dashboard.title")}</h1>;
}
```

## Estrutura

```
src/contexts/i18n.tsx
├── pt-BR (padrão)
├── en
└── es
```

## Adicionar Idioma

1. Adicionar objeto de traduções em `i18n.tsx`
2. Adicionar opção no LanguageSelector
3. Testar todas as strings

## Formatação

- Datas: `toLocaleDateString(locale)`
- Números: `toLocaleString(locale)`
- Moeda: `Intl.NumberFormat`
